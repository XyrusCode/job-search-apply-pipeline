# Resumes

Drop your own role-specific resume PDFs here. Filenames must match `config/role-resume-map.json`
(the pipeline skips a role whose resume is missing and logs why):

| Role | Example filename |
|---|---|
| Frontend | `frontend-resume.pdf` |
| Backend | `backend-resume.pdf` |
| Full Stack | `fullstack-resume.pdf` |
| Mobile | `mobile-resume.pdf` |
| DevOps | `devops-resume.pdf` |

Rename the files in your runtime `config/role-resume-map.json` if you prefer different names. Never
substitute a different role's resume. PDFs (and .docx files) in this folder are git-ignored — personal
documents never enter version control.
